## 📚 O que aprendi

Durante este projeto pude praticar conceitos importantes de desenvolvimento front-end, como:

- Estruturação semântica com HTML5
- Estilização e organização de layouts com CSS
- Flexbox e CSS Grid
- Responsividade para diferentes tamanhos de tela
- Manipulação da DOM
- Eventos com `addEventListener`
- Criação de carrosséis utilizando JavaScript
- Navegação entre seções através de âncoras
- Interações utilizando eventos de toque
- Controle de elementos através de classes CSS
- Organização de uma interface para um projeto real
- Aplicação de conceitos básicos de acessibilidade e SEO

Além da proposta de estudo, personalizei completamente a interface do projeto, trabalhando identidade visual, hierarquia de conteúdo, experiência do usuário e adaptação do layout para desktop e mobile.
